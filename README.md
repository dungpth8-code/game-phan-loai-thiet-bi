# 🚀 Siêu Nhí IT - Phân Loại Thiết Bị

Game giáo dục dành cho học sinh lớp 6, giúp các em phân loại thiết bị máy tính thành **Thiết bị Vào (Input)**, **Thiết bị Ra (Output)**, hoặc **Vừa Vào Vừa Ra (Input/Output)**.

## 🎮 Cách chơi

1. Kéo thả thẻ thiết bị vào đúng cổng phân loại
2. Mỗi lượt chơi có **10 câu hỏi**, mỗi câu **5 giây**
3. Trả lời đúng: **+10 điểm** | Sai hoặc hết giờ: **-5 điểm**
4. Có tính năng **🤖 Gợi ý AI** (sử dụng Gemini API)

## 🛠️ Công nghệ

- HTML5, TailwindCSS, JavaScript
- Tone.js (hiệu ứng âm thanh)
- Gemini API (tính năng gợi ý AI)

## 📖 Chạy game

Mở file `index.html` trên trình duyệt để chơi ngay!
